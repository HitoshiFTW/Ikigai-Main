## Day 68 (June 7-8) -- The compositional stack scales

Morning opened with Prince's question that locked the architectural framing: *"What if we introduce loop learning?"* Day 67 had shipped Pack 224-226 as a one-shot stack -- observe, lift, induce, generate. The toy corpus reached fluent SVO. The honest concern was whether one-shot would survive scale. The architectural commitment had already dropped one-shot learning in Day 67 mindset.md rule 5; rule 6 now made it operational: SLEEP becomes an iterative error-driven refinement loop.

Pack 227 implemented the generalized delta rule for SDM. Walk each chain. At each `(a, b)` transition, predict via current FSM step (Resonator-decoded over candidates). If the prediction matches actual, write `relate(a, next, b)` x `hebbian_strength`. If wrong, write `unrelate(a, next, predicted)` x `delta_strength` (subtract the wrong attractor via Kill-Stack #4 Reversible Writes) and `relate(a, next, actual)` x `delta_strength` (add the right one). Track per-epoch accuracy. Stop on convergence. The mechanism reused two primitives shipped on Day 60: Reversible Writes (Pack 162) for the subtract, and Substrate-Native Gradient (Pack 167) for the additive update. Both had been sitting in `multirole_memory.py` waiting for a learning loop to call them. Pack 227 was that loop.

Smoke result on 14-sentence corpus x 3 (42 chains, starting from empty substrate): `epoch 1 acc=0.342 -> epoch 2 acc=0.442 -> epoch 3 acc=0.408 (converged)`. The 10-percentage-point jump after the first delta epoch was the loop-learning signature. Delta writes per epoch: 96 -> 82 -> 87, corrections decreasing as basins carved cleanly. The 44% ceiling was traced to per-state entropy: the bigram FSM saw 5 valid continuations for `the cat` in the corpus, so it could not exceed 1/5 + within-class agreement on that state. Higher accuracy needed trigram conditioning. Pack 225's `do_trigram=True` already piped `next2` recall into `step()`; Pack 228 leveraged it.

Pack 228 ran the same delta rule but with `(prev_token, current_token) -> next_token` instead of `current_token -> next_token`. The delta writes went to both `next` and `next2` roles on miss. State `(prev=the, current=cat)` became distinct from `(prev=small, current=cat)` so each anchored its own attractor. Smoke result on the same 42-chain corpus: bigram `epoch 1 0.342` vs trigram `epoch 1 0.479` (+13.7 pp); bigram `epoch 5 0.408` vs trigram `epoch 5 0.701` (+29.3 pp). Delta writes per epoch decayed 76 -> 55 -> 47 -> 45 -> 44, basins carving cleanly. Generation correctness: bigram `small cat on the bird drank dog` (state-blind drift) vs trigram `small cat caught mouse the cat ate fish` (correctly disambiguating `small cat -> caught` from `the cat -> ate` per corpus statistics). The trigram FSM had passed its first real test.

Pack 229 wrapped the Day 67-68 commitment into one entry point: `IkigaiOrganism.sleep_pack229(texts, n_epochs, delta_strength, ...)` runs `fsm_lift_abstract` -> `fsm_induce_schemas` -> `fsm_iterative_refine_trigram` in sequence. Toy result on 14 sentences x 3: 69 isa-parent transitions, 3 schemas (`['_', 'animal', 'action', '_']` support 30; `['determiner', 'animal', 'action', 'preposition', 'determiner', '_']` support 9; `['adjective', 'animal', 'action', 'preposition', 'plant']` support 3), refine peak 70.1% in 1.1 seconds end-to-end. Generation: `small cat -> small cat caught mouse the cat ate fish` (perfect SVO + disambiguation); `a dog -> a dog sat on the tree` (fluent prep phrase); `the cat -> the cat ate fish action food the cat` (correct then drifts into abstract tokens). The Day 67-68 compositional substrate was complete on the toy.

Pack 230 was the first scale bisection. Wikipedia 500 articles (1500 chains, vocab 3079) ran `sleep_pack229` for ~32 minutes. 11,499 bigram transitions, 11,878 lifted transitions, **zero schemas induced**. The length-grouping in `induce_schemas` collapsed to all-SLOT across heterogeneous wiki patterns. Delta refine epochs: 0.074 -> 0.149 -> 0.234 -> 0.307 climbing, suggesting it would go higher with more epochs. Generation broken because the tokenizer kept punctuation and proper nouns. Hand-curated comparison run: 200 sentences across 5 grammar patterns, 75 tokens, 76 isa assertions, 6.2-second sleep, 1 schema (length-6 `[determiner, animal, action, preposition, determiner, place]`), peak 0.244 (lower than wiki because per-state entropy on a smaller vocab is higher), but **fluent SVO English on every test seed**: `the cat is big`, `a dog slept at a tree`, `the horse walked in the river`, `happy fox flew on a house`. The verdict: architecture is proven. The wall is the length-grouping. The substrate and delta rule scale; the schema induction step needs clustering BEFORE anti-unify. Curated 200 sentences had 160 length-4 sentences spread across 4 different abstract patterns, and the length-bucket anti-unify averaged them out to all-SLOT.

Pack 231 introduced substrate-native HV clustering of abstract chains. Within each length bucket, build the chain's HV via existing positional roles (pos_0..pos_7 shipped Day 60 Pack 199 NEW2). Greedy nearest-centroid cluster: each chain joins the nearest cluster by cosine > tau, or spawns new. Within each cluster (>= min_cluster chains), anti-unify into a schema. v1 dropped length-bucketing and went pure HV-cluster across all chains; this merged length-4 with length-6 chains that shared early-position tokens, producing cross-length spurious merges. v2 used length-bucket FIRST then HV-cluster within. The correct ordering. Smoke results: curated 200 sentences went 1 schema (Pack 226 baseline) -> 2 schemas (v1) -> **3 schemas** (v2, perfect structural split -- len=4 cluster size=120 merged patterns 1+3+4 since they share `[det/adj] animal action [food/adj]`, len=4 cluster size=40 isolated Pattern 5 `det adj animal action`, len=6 cluster size=40 isolated Pattern 2 `det animal action prep det place`). Wiki 1500 chains went 0 schemas (Pack 230 v1) -> 1 schema (v1) -> **6 schemas** (v2 at tau=0.70 -- matching the hand-asserted baseline from earlier curated runs without any taxonomy at all).

The schemas' token labels were noisy because of the mass-balance problem. `action` category had 47 children x 15 reps each = 705 isa writes; `determiner` category had 2 children x 15 reps each = 30 writes. The 8192 hard locations of the relational bank shared all those writes; bank crosstalk biased `recall(w, 'isa')` toward dominant targets; `_isa_parent` returned 'action' for words that should resolve to 'determiner'. The CLUSTER SIZES were correct (120/40/40 perfectly matching pattern distributions); only the abstract LABELS in the resulting schemas were biased.

Pack 232 normalized this. `assert_isa_balanced(taxonomy, total_per_category=N)` distributes target N total isa writes evenly across the children of each category, with `min_per_word` floor. Per-word reps become `total_per_category // len(category)`. On the curated 200 corpus the probe quality jumped: `fish` (in both SUBJECTS and OBJECTS) had returned `animal` in the imbalanced case (popular class won), now returned `food` correctly. The fix was real for label correctness but did not unlock new schemas, because the root cause was not just mass imbalance -- it was the VSA-SDM bank-level crosstalk inherent to writing thousands of bindings into 8192 shared locations. The substrate-native cluster discovery (Pack 231 v2) survives this crosstalk because clustering is over chain HVs in concept space, not over per-token recall lookups. But the labels on the resulting schemas are still corrupted by the bank crosstalk.

The root cause was the architectural assumption that the substrate should be TOLD the isa taxonomy. Pack 233 attacked this assumption head-on. Drop hand-asserted isa entirely. Let the substrate cluster its own vocabulary by distributional context similarity. For each vocab token `w` with `freq >= min_freq`, build the context HV via Hadamard-bind under two distinct positional roles: `hv = (recall(w, 'next') * pos_0_role) + (recall(w, 'cooccur') * pos_1_role)`. The `next` channel captures right-context (the word that follows w); the `cooccur` channel captures bag-of-context (words within the same passage). Binding them under distinct positional roles prevents the channels from collapsing into a single mixed signal. Greedy nearest-centroid cluster on the resulting context HVs. Most-central token per cluster becomes the label (e.g. `pos_0__the`). `_emergent_parent(word)` replaces `_isa_parent(word)` in all downstream schema discovery.

Smoke result on the curated 200 corpus, **no isa asserted, tau=0.70**:

cluster 5 (40): bird, bone, brave, cat, cried, dog, ... -> residual mixed

5 of 7 emergent classes were grammatically pure. Zero hand-assertion. Schema discovery via Pack 233 emergent POS gave 4 schemas vs 1 with hand-asserted isa. The substrate was its own classifier. This was the AGI-path unlock: it scales to any corpus where words have stable distributional contexts, which is all natural language.

On the curated 200 corpus the modules fired correctly (200 frame routes, 191 unique SVO triples, importance records for every chain) but the outputs did not feed downstream phases -- frame_field's routing decisions did not condition the schema_induction phase; crystallizer's triples were observed but not written to the schema_next role; importance_decay's records were not used to weight delta_strength. Pack 236's filter was correct. The bug was the test seeds. The 8192 hard locations of the relational bank have finite capacity; flooding them with `the -> X` writes degrades every other transition's signal-to-noise ratio.

Pack 197 already ships the right primitive: `MultiRoleMemory.write_strength(token) = log(N / count(token)) / log(N)`. Frequent function words get 0.05x writes; rare semantic words get 1.0x writes. The `expose_cooccur(text)` path uses it. The `fsm_observe(text) -> relate(a, 'next', b)` path does not. Pack 238 = add `write_strength(a)` and `write_strength(b)` scaling to the `relate` call inside `observe_chain`. Then stopwords can survive without flooding. Then generation seeds work AND accuracy stays high.

## Appendix B -- The substrate-protection mechanism, formally

The 8192 hard locations of the relational bank (Kanerva SDM tile addressing) share all role-bound writes. Every `relate(word, role, target)` call distributes activation across some subset of these locations via the address computation `addr = key(word) * (frame_hv * role_hv)`. The subset size depends on the address's binding pattern but is bounded by the bank dimension.

When `M` writes to the bank concentrate on a small subset of locations (call it `S`), the locations in `S` accumulate `M / |S|` activation each on average. Their signal-to-noise for any one of the `M` source bindings degrades roughly as `1 / sqrt(M / |S|) = sqrt(|S| / M)`. For typical SDM dimensions `|S| ~ 200`, every additional 1000 writes to the same address subset cuts per-write SNR by `sqrt(1/5)` ~ 0.45x. After 10000 writes, per-write SNR is ~0.14x of single-write baseline.

Stopwords are exactly the source of this degradation. In a 2000-sentence simple_wiki corpus, `the` appears ~12000 times. Without frequency capping, every `the -> X` transition writes to the `(the, next)` address subset. After 12000 writes, the per-binding SNR is ~0.13x of the single-write baseline. Recall queries to `(the, next)` retrieve a noisy average of all 12000 transitions, biased toward whichever target appeared most often (`of`, `same`, etc.). Worse: any OTHER word's `cooccur` recall picks up `the` direction because `the` co-occurs with everything, polluting every other context HV with the dominant stopword vector.

Pack 236's `freq <= 500` cap prevents this by simply dropping stopwords from the corpus before the substrate sees them. Pack 237 confirmed empirically that without the cap, accuracy collapses from 0.787 to 0.445 -- a 34-percentage-point regression from removing one filter. The substrate IS the bottleneck; the data prep IS substrate protection.

Pack 197 already ships the architecturally correct fix: `write_strength(token) = log(N / count(token)) / log(N)` scales each write by inverse frequency, so the `M` writes for `the` accumulate as ~5% of full-strength writes instead of 100%. Per-binding SNR for the dominant attractor stays controlled even with all 12000 writes attempted. The `expose_cooccur(text)` path uses this gate. The `fsm_observe(text) -> relate(a, 'next', b)` path does not.

Pack 238 = add `write_strength(a)` and `write_strength(b)` scaling to the `relate` call inside `observe_chain`. One line. Then:
- Stopwords survive the corpus filter (no upper frequency cap needed).
- Stopword writes are scaled down to ~5% strength per write at the bank.
- Per-binding SNR for the `the -> X` attractor stays ~`sqrt(12000 * 0.05 / 200)` = ~`sqrt(3) / sqrt(200)` ~ 0.12 (controlled, not degenerate).
- Rare semantic word transitions stay at full strength.
- Generation seeds with stopwords work.
- 78.7% accuracy holds.

This is the formal reason Pack 238 is the right next pack. The mechanism is shipped (Pack 197 Day 64). The wire is missing. The fix is one line. The expected result is preservation of the 78.7% headline AND restoration of stopword-prefixed generation seeds.
