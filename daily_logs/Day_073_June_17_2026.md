## Architecture

```
General Reasoning Pipeline (Pack 255):
    tokenize(text)              [cat-3 digit-aware lexer]
        ↓
    state_hv(toks)              [Pi_k-permuted superposition of token HVs]
        ↓
    PARALLEL:
      next_predict via fsm.step()             [cat-1 floor]
      magnitude scan: recall(t, 'magnitude')  [FPE decode each token]
      goal-directed: MultiStepPlanner.plan()  [if goal given]
      closure: LogicalFixedPoint.run()        [if do_closure=True]
        ↓
    cleanup_decode(hv, 'cooccur')   [Pack 247z-CM common-mode]
        ↓
    return {answer, method, magnitudes, plan, next_predict, ...}

Pack 251 OnPolicyEvaluator (per-triple plasticity gate):
    predict = fsm.step(prev, cur)
    if predict == actual:
        bank.C[locs] += 0.3 * α * key(actual)         YES (weak reinforce)
    elif predict is None:
        bank.C[locs] += 1.0 * α * key(actual)         NOVEL
    else:
        bank.C[locs] -= β   * key(predict)            NO un-learn
        bank.C[locs] += α   * key(actual)             NO learn correct

Pack 252 NumericEncoder (FPE on FHRR substrate):
    phases ∈ R^d  random uniform [-π, π]
    encode(x): exp(i · x/scale · phases)              unit phasor
    Z^a · Z^b  = Z^(a+b)                              Hadamard = add
    Z^a · conj(Z^b) = Z^(a-b)                         conj-mul = sub
    decode(hv): argmax over candidate x grid

Pack 253 Cat3Absorb (one chain → 3 substrate writes):
    1. opv.gated_observe(prev, cur, next, 'next')    [251 gate per pair]
    2. for digit tokens t:
         mr.write_relation(t, 'magnitude', enc.encode(parse_int(t)))
    3. mr.expose_cooccur(' '.join(toks))             [windowed binding]

Pack 254 substrate_arith (no eval, no router):
    parse(problem) → (left_tok, op, right_tok)
    left_hv  = recall(left_tok,  'magnitude')        [direct binding]
              or cooccur → digit_tok → recall(digit, 'magnitude')   [emergent]
    right_hv = same path
    result_hv = enc.add(left, right) or enc.sub(...)
    answer = enc.decode(result_hv).argmax → int
```

## What Broke and What I Learned

- **Vast.ai auto-supervisor.** Their `/opt/supervisor-scripts/vllm.sh` runs its own vLLM on port 8000 that respawns whenever killed. Cost 30 min before I saw it. Fix: `supervisorctl stop vllm` once, then use port 8001 for our serve.py.
- **CUDA ghost VRAM after OOM.** Process killed but driver-side allocation persisted. `nvidia-smi --query-compute-apps=pid | xargs kill` fixed it. Two BSODs on Day 72 GPU SVD made me CPU-default for the local Qwen path.
- **Stream buffer on Windows pipe.** Python stdout to bash background file = full buffering even with `flush=True`. Fixed via `sys.stdout.reconfigure(line_buffering=True)` + `PYTHONUNBUFFERED=1`.
- **`AttributeError: property 'reasoner'`.** Old `self.reasoner = ReasoningEngine()` at line 220 collides with new property. Renamed Pack 255 property to `general_reasoner` (kept old `reasoner` for call-site compat).
- **Day 72 UDSP lesson held.** When PCER research return arrived (Pack 255 spec), I marked half of it speculative. Built only what existing primitives could deliver. Pack 256/257/258 stay deferred.
- **deleted `/github` by accident.** Chained `rm -rf /github && rm _pack137.jsonl` into one bash call; user rejected the second but the first already ran. Recovered by re-cloning `https://github.com/HitoshiFTW/Ikigai-Main`. `flatmem` was already in `.venv` via pip. Lesson: never chain destructives in one Bash tool call.
- **Garbage cleanup paid off.** 1.4 GB old organism.ikg backups removed. 67 stale `_pack*.log` logs trimmed to 5 (day73 only). Codespace clean.
