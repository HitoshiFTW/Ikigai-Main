## Architectural notes (5 lessons)

1. **Eval regime matters more than wires.** The 0.057 → 0.065 ceiling-break at 2K corpus was real for that regime but inverted at 10K. At realistic scale the substrate alone hits 0.071 top-1 / 0.0553 UNSEEN. Every wire experiment from Pack 245C onward was tuned against an artifact regime. **Future packs must validate at 10K BEFORE shipping permanent.**

2. **Common-mode removal is the universal sharpener.** Worked at HSP input (Phase 1c → 6.10x), worked at HSP input with NEXT-only (Phase 3 → 20.42x), worked at substrate READ (Phase 4-B → +0.011 top-1 alone). Linearity preserves role-binding algebra. Single most impactful primitive of Day 70-71. Should be the FIRST thing tried on any future signal-extraction problem.

3. **PPMI > raw counts > row-normalization.** Successor leakage in HTM col-pair matrices is fundamental. Frequency-biased smoothing α=0.75 from word-embedding literature carries over cleanly. Row-norm alone scales only outbound; doesn't fix inbound popularity bias.

4. **Substrate-confidence gating is the real wire architecture.** Wires that boost are dangerous: they can move a correct substrate top-1 to a wire-preferred wrong candidate. Confidence gate (skip wires when substrate top-1 - top-2 margin > threshold) is the structurally correct pattern. Future wires should default to gated.

5. **POS oracle as info-theoretic floor test is a free diagnostic.** NLTK pos_tag, 11 classes, 30s build. If oracle UNSEEN ≈ 0.001 → info-theoretic; if > 0.01 → extractability. Should run at every scale step.

## Appendix B -- The hardcode bug (formal documentation)

`integrate.py:__init__` signature was `def __init__(self, d=400, flat_only=False)`. The `self.d = d` captured the param but every internal instantiation ignored it:

```python
# Before fix:
self.flat       = None if flat_only else FlatMemory(d=512, M=16384, k=64, seed=114)
self.unified    = MultiRoleMemory(d=512, M=16384, k=64, seed=114)
self.frames     = FrameField(d=512, K=8, top_n=64, seed=42, alpha=0.5)
self.curiosity  = CuriosityDrive(d=400)
self.tom        = TheoryOfMindSandbox(d=400)
self.vsa        = VSACalculus(d=400)
self.belief     = BeliefField(d=400)
self.verifier   = SelfVerifier(d=400, threshold=0.5)
self.proof_gen  = ProofCarryingGenerator(d=400)
```

The organism.ikg on disk was saved at d=400 (Pack 245G+ retrains). On load_ikg, the .ikg-saved MultiRoleMemory state restored MR at d=400, OVERWRITING the constructor's d=512 instance. But FrameField was NOT restored from .ikg in the same path (frames pickled separately, came back at whatever the constructor created -- d=512). Result: `org.frames.d == 512` but `org.unified.d == 400`. First `route_passage(tokens, mr.ck)` call: `accum = np.zeros(512); accum + ck.key(t)` where ck.key returns d=400 → ValueError shape (512,) + (400,).

Fix (permanent):

```python
self.flat       = None if flat_only else FlatMemory(d=d, M=16384, k=64, seed=114)
self.unified    = MultiRoleMemory(d=d, M=16384, k=64, seed=114)
self.frames     = FrameField(d=d, K=8, top_n=64, seed=42, alpha=0.5)
self.curiosity  = CuriosityDrive(d=d)
self.tom        = TheoryOfMindSandbox(d=d)
self.vsa        = VSACalculus(d=d)
self.belief     = BeliefField(d=d)
self.verifier   = SelfVerifier(d=d, threshold=0.5)
self.proof_gen  = ProofCarryingGenerator(d=d)
```

This was a silent corruption path that would have bitten every multi-d experiment. Prince caught it directly ("why hardcode?") inside Pack 247e. Now fixed in one commit, all 9 hardcoded d= values normalized to `d=d`.

## Appendix C -- 10K scale shock (formal record)

**Configuration:** 5000 simple_wiki articles → 25K sentences → 20K TRAIN / 5K HELDOUT → 116852 train bigrams → 29244 heldout predictions over 2739 candidates. organism.ikg loaded fresh (Phase 4-B baked stack). PPMI transition matrix rebuilt on TRAIN distribution.

**Result:**

```
RAW substrate     top-1 0.071   top-5 0.082   SEEN 0.097   UNSEEN 0.0553
FULL STACK       top-1 0.063   top-5 0.109   SEEN 0.110   UNSEEN 0.0361
```

**Reading:**
- RAW substrate UNSEEN 0.0553 at 10K vs 0.0010 at 2K = 55x relative increase. Same substrate. The substrate has been generalizing all along — narrow 2K eval just couldn't see it.
- FULL STACK at 10K is WORSE than RAW: top-1 -0.008, UNSEEN -0.0192 (35% relative drop).
- The wires were tuned at 2K where substrate is weak. At 10K substrate is strong enough that wire reordering does net damage.
- top-5 still favors FULL STACK (0.109 vs 0.082) suggesting wires help DIVERSITY of top-5 but hurt CORRECTNESS of top-1.

**Implication:** every wire-tuning pack from 245C onward was optimizing against the wrong regime. The 5.4% structural floor diagnosed by Day 70 research may have been a narrow-eval artifact, not a fundamental flat-VSA property. THE FLIP becomes even more attractive — absorbing LLM topology onto a 0.071-baseline substrate is multiplicative, not rescue.

**Action:** substrate-confidence gate added to `predict_with_wires`. Per-wire breakdown queued. Eval default moves to 10K. Future doctrine: validate at 10K BEFORE locking any wire.
