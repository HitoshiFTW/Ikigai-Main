## 5. Pack 279 -- Compact Cache (6.78x Shrink)

Pack 273 + Pack 274 stored the anchor-action cache as `dict[str_anchor, list[tuple[str]]]`. String anchors like `'__state_701357096285'` consume 70 bytes; list-of-tuple values like `[('paris',)]` consume ~170 bytes; dict slot overhead ~32 bytes. Profiled per-entry footprint: 288 bytes (close to the 270 projected at Day 76 close). At 10^6 facts that footprint is 270 MB -- exceeds the 192 MB substrate cap.

Pack 279 swaps the representation to `dict[int64, bytes]`:

* Key: 8-byte int (the raw blake2b digest used to produce the original string anchor).
* Value: utf-8 encoded action token bytes (~10 bytes average for single-word answers).
* Last-wins semantics on duplicate anchor writes (matches Pack 273 runtime read pattern which already took the LAST entry of the value list).

`CompactAnchorCache` ships in `ikigai/cognition/cat4_compact_cache.py` with a back-compat shim: `__getitem__` / `get` accept string anchors and return list-of-tuples, so general_reasoner and cat4_dopamine require no changes.

Production smoke: load existing organism (legacy dict cache), automigrate on attach via sample-type sniff (bytes -> Pack 279 state, list-of-tuples -> legacy migrate), 25/25 bench preserved, save+reload survives with compact persistence. Measured per-entry: 42.5 bytes = 6.78x shrink. Projected: 1M facts = 40.5 MB (under 192 MB cap), 1B = 40.5 GB (LMDB territory).

`integrate.py` cat4 lazy property does the sniff-and-migrate; `_sync_cat4_cache_for_persist` writes the compact `dict[int, bytes]` to `_cat4_anchor_actions_cache` for pickling. organism.ikg disk size unchanged at 182.5 MB (substrate dominates; cache 235 KB -> 35 KB is invisible). The win is at scale.

Backup: `organism.ikg.bak_pre_pack279`.

## 6. Pack 280 -- Vectorize recall_action (28 s -> 77 ms = 364x)

The Day 76 close articulated this pack as "the single biggest latency unblock pending in the locked queue." Pack 280 stacks all stored state hyper-vectors into a `(N_anchors, d)` complex64 matrix cached on the Cat4Absorb instance and replaces the per-anchor Python loop in `recall_action` with one matmul plus an `argpartition` top-K selection.

Implementation:

1. New instance attrs `_pack280_recall_states`, `_pack280_recall_bounds`, `_pack280_recall_anchors`. Built lazily on first `recall_action` after invalidation.

2. `_pack280_build_recall_cache` iterates `pair_role` anchors, calls `mr.recall(a, state_role)` + `mr.recall(a, pair_role)` for each, stacks the results.

3. New `recall_action` body: single `states.conj() @ query_state` matmul -> per-anchor sims, argpartition -> top-K, per-row action_est unbinding for the returned tuples.

4. Incremental update on `absorb_chain`: for each new (state_hv, bound_norm) write, append one row to each matrix in place (existing anchor overwrite via index lookup; new anchor vstack). Never invalidates the full cache during teaching.

Smoke results:

* Cold rebuild (one-time per session): 142.6 s for the production 63,917-anchor substrate.
* Hot avg over 4 queries: 76.8 ms, range 65-87 ms.
* Speedup vs old 28 s loop: 364x.
* Memory cost: 390 MB (195 MB states + 195 MB bounds at N=63,917). Under the 1 GB cache ceiling.
* Incremental absorb path: new anchor recall returns top_sim=1.000 immediately, no re-cold.

The cold cost is not persisted to organism.ikg -- session start pays it once. Sidecar disk-cache for `_pack280_recall_states` is a potential Pack 280.5 if startup latency becomes user-visible. Per-fact teach time drops from ~3 min (Pack 276 dopamine retry running 6 cleanup iterations at 28 s each) to ~0.5 s; the 1M-fact teach pipeline now fits in a single 3090's overnight budget.

## 10. Pack 291 + 291.5 + 291.6 + 291.7 -- Full Substrate-Native Arithmetic Ring

Pack 291 implements multiplicative ⋆ binding per Kymn et al. 2023 §4.1.2. New methods on `ResidueHDC`:

* `_ensure_antibases()` -- precompute per-modulus modular-inverse anti-base phasor arrays via `pow(uu, -1, m)` per element. Rejects composite moduli with ValueError (the modular inverse exists only when gcd(u, m) = 1; for prime m every nonzero u qualifies).
* `encode_factored(x)` -- per-modulus list of HVs, length K (skips the bundling step in `encode`).
* `bundle_factored(factors)` -- recover bundled HV by per-modulus Hadamard product.
* `mul_factored(fa, fb)` -- the ⋆ operator. Per modulus: extract residues r, s from each phasor via `angle * m / (2π)`, compute `(r*s) mod m`, multiply by the anti-base residue `v_j` so the per-element u_j^2 factor cancels back to u_j * x1 * x2.
* `multiply(fa, fb)` -- alias returning bundled output.
* `mul_int(x1, x2)` -- end-to-end test path (encode + ⋆ + decode).

Smoke: 50/50 random pairs in [0, 100]² + 8/8 small + 3/3 medium + composite-modulus ValueError on (3, 4, 5). Production moduli (5, 7, 11, 13, 17, 19, 23, 29) all prime so multiply works for the 1.08B-range organism out of the box.

## 12. Pack 285 v0 + Pack 285.5 -- SBC Encoder Breaks Cleanup Wall

Per Hersche-Vasilache-Sebastian (NAI-240713 2025) and Frady-Kleyko-Sommer 2021. Pack 285 v0 ships `SBCEncoder(d=400, B=40, L=10)` in `sparse_block_codes.py`. Reshape the d-dim phasor substrate as B blocks * L slots; each token's encoding activates exactly one slot per block (B-tuple of within-block slot indices). Cleanup = B independent argmax over L per block = O(d), constant in vocabulary size N.

**Cleanup wall broken: 10,000 / 10,000 at d=400 at 91 us per query.** Frady-Sommer literature caps random-phasor cleanup at d=400 at ~20 items; SBC reaches 10,000 because cleanup time decouples from N. FHRR baseline at same N=10,000 takes 9,274 us per query (>100x slower).

Limitations measured + matching the literature:

* Noise tolerance brittle: 100% at sigma=0, 0% at sigma >= 0.5. Needs smooth phasor priors or resonator integration.
* Superposition fails past k=1: block argmax confuses multi-active blocks. Recovers k=1 cleanly.
* Hadamard binding does not unbind by FHRR rules. Hersche §3.2 uses block-permutation variants; we do not yet.

Pack 285.5 built `SBCActionCodebook` as a parallel research primitive. Registers the cat-4 action vocabulary (9616 tokens) into SBC encoding in 0.36 s. `cleanup_token([state_tokens])` does deterministic blake2b -> B-tuple -> registered-vocab lookup at 38.8 us versus FHRR matmul 8987 us (231.9x). Runtime kill switch `disable(reason)`. Smoke 5/5 hits + 3/3 misses + 25/25 production bench unchanged.

**Honest caveat**: SBC `cleanup_token([t])` is fundamentally a deterministic anchor lookup. Single state-token `[paris]` matches the registered `paris` vocab tuple because both use the same blake2b hash. Production queries like "What is the capital of France" hash differently. FHRR substrate writes do not project to SBC space. Real Pack 285.5 wiring requires SBC-bound substrate writes (a re-architecture, not a retrofit). Shipped as research primitive with kill switch; production reasoning unchanged.

## 13. Pack 287 v0 + Pack 287.5 v0 + Pack 287.5 v1 -- KL-RPE Continuous Graded Fire

The bool substring match in Pack 276 dopamine is the biological violation Schultz 1997 specifically measured against: real VTA firing is graded, not binary. Pack 287 v0 ships `KLDopamine(Cat4Dopamine)` in `cat4_dopamine.py`:

* `_kl_fire(toks, expected)` = exp(-KL(teacher_one_hot || P_sub)) ≈ P_sub mass at the expected token.
* `reason_until_graded(query, expected)` -- like reason_until but the converged condition is fire >= fire_threshold (default 0.30) rather than a substring match.

Smoke: knowns 6/6 fire=1.000 (cache delta), unknowns 4/4 fire=0.000 (no token match in cleanup), clean discrimination at the 0.30 threshold.

## 14. Pack 288 -- Parallel Particle-Swarm Cleanup

Pack 276's sequential noisy-retry loop runs N noise levels sequentially: total wall = N * 77 ms = ~600 ms for N=8. Pack 288 vectorizes the loop: stack N noise-perturbed `focus_hv` variants as a single (N, d) query matrix, do one matmul against Pack 280's (N_anchors, d) stored states, get (N, N_anchors) per-particle sims, per-particle top-1, majority vote on action token.

`KLDopamine._swarm_predict(query_toks, n_particles=8, sigma=0.05)` ships in `cat4_dopamine.py`. Two-tier (mirrors Pack 287 `_substrate_distribution`):

1. Pack 273 cache fast-path -- deterministic anchor hit -> delta consensus (8/8 same token).
2. Cache miss -> swarm: N noise-perturbed focus_hv variants, single matmul, vote.

Cache fast-path wall: 0.05 ms (8000-10000x faster than 8 sequential `recall_action` calls). Cache miss swarm wall: 74 ms (6.6x faster than 8 sequential). Knowns return consensus delta via fast-path. Unknowns vote 8/8 empty (substrate has no anchor). Noise sweep on Greece (cached) returns 'athens' across all sigma 0-0.5 because fast-path bypasses noise.

True swarm value emerges during teaching (cache cold). Cache fast-path dominates production behavior post-teaching.

## 20. What The Organism Does Now

The organism reads a query, runs it through the substrate-native math eval if compositional (Pack 254 add/sub + Pack 291 mul + Pack 291.7 div, all via cat-3 emergent operator grounding with zero hardcoded lexicon), or falls through to the cat-4 ICL path otherwise.
